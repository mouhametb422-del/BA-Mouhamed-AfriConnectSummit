## Description du projet

AfriConnect Summit est un site web vitrine consacré à un sommet technologique panafricain organisé à Dakar, au Sénégal.

Le site permet aux visiteurs de découvrir l'événement, consulter le programme des conférences, découvrir les intervenants, s'inscrire en ligne et accéder aux différentes informations pratiques.

Ce projet a été réalisé dans le cadre de l'examen de Développement Web en Licence 1 ISI.

## Fonctionnalités JavaScript

- Menu hamburger responsive
- Mode sombre / mode clair
- Compte à rebours avant le début de l'événement
- Compteurs animés des statistiques
- Animations au scroll avec IntersectionObserver
- Onglets interactifs de la page Programme
- Filtrage des intervenants par catégorie
- Validation du formulaire d'inscription
- Bouton "Retour en haut"
- Mise à jour automatique de l'année dans le footer
